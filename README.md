## Project Description
This project is an interactive to-do list application built to practice DOM manipulation and event handling in JavaScript. It allows users to add tasks, mark tasks as complete, delete tasks, filter tasks, and clear completed tasks.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Features
- Add new tasks using a form
- Mark tasks as completed or active
- Delete individual tasks
- Filter tasks by all, active, or completed
- Clear all completed tasks
- Display total, active, and completed task counts
- Handle click, input, submit, and keyboard events
- Manipulate DOM elements, attributes, classes, text content, and styles

## How to Run
1. Clone this repository:
   ```bash
   git clone https://github.com/mordzy101/iyf-s10-week--05---mordzy101-.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

## Lessons Learned
While building this project, I learned how to select DOM elements, create new elements, update text content, change attributes, add and remove classes, and update styles using JavaScript. I also practiced using event listeners for form submission, button clicks, input changes, and keyboard events.

## Challenges Faced
One challenge was making sure the task list updated correctly whenever the user added, deleted, completed, or filtered tasks. I solved this by storing tasks in an array and using a `render()` function to update the page whenever the data changed.
